# Sistema Academico

## Modulo de calificaciones

Este proyecto permite calcular el promedio de un estudiante
y determinar si aprobo o reprobo.

## Reglas del sistema

1. El sistema recibe tres notas.
2. Las notas deben ser numeros.
3. Las notas deben estar entre 0 y 100.
4. El promedio se calcula sumando las tres notas
   y dividiendo el resultado entre tres.
5. El estudiante aprueba con un promedio igual o superior a 60.
6. Si el promedio es inferior a 60, el estudiante reprueba.
